## SecureBank Threat Modeling & Security Assessment
**Technologies:** Python, Flask, JWT, Pytest, Semgrep, Trivy, Gitleaks, GitHub Actions

- Conducted STRIDE-based threat modeling for a demo banking API and documented threats, mitigations, and residual risks.
- Implemented and tested JWT authentication, object-level authorization, role-based access controls, structured audit logging, and API rate limiting.
- Developed regression tests for authorization failures, JWT validation, audit-log integrity, HTTP method restrictions, and rate-limit enforcement.
- Integrated automated security checks into GitHub Actions using Pytest, Semgrep, Trivy, and Gitleaks.
- Achieved 35 passing local tests and a successful CI workflow run for the documented project revision.
